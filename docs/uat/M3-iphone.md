# M3 iPhone 測試清單(給 Gerald)

這次要確認的是「備份」功能在 iPhone 上真的能用:把資料存到「檔案」App,之後再從「檔案」還原回來。
大約需要 15 分鐘。照順序做,每做完一步就打勾;看到的和清單寫的不一樣,記下**步驟編號**和**你看到什麼**就好,不用自己判斷原因。

> ### ⚠️ 先看這裡:資料安全
> - 如果 Reset66 裡已經有你真實的打卡紀錄:**更新完成後,第一件事就是做 C 段「匯出備份到檔案」**,確認檔案存好了,再做後面的測試。
> - 從 C 段開始到 E 段做完之前,**不要在今日頁打勾或略過任何習慣**,這樣還原時才不會少掉剛打的勾。
> - **不要把真實的紀錄、備份檔或有紀錄的截圖貼到 GitHub(Issue、留言都不行)**,repo 是公開的。有問題用文字告訴 PM 交談就好。

---

## A. 更新到新版本

- [ ] **1.** 從主畫面打開 Reset66。
- [ ] **2.** 點下方的「設定」,捲到最下面的「關於」。
  - 看到 `版本 0.3.0 · reset66-v3` → 已是新版,跳到 **B 段**。
  - 看到別的版本號,或設定頁沒有「備份」區塊 → 做第 3 步。
- [ ] **3.** 把 app 完全關掉:從螢幕最下方往上滑並停住,出現多個 app 卡片後,把 Reset66 的卡片往上滑掉。再從主畫面重新打開,回到「設定 → 關於」看版本。
  - 如果你的 Reset66 是很早的版本(M0),可能要**再關掉、再打開一次**才會更新。
- [ ] **4.** 確認「關於」顯示 `0.3.0 · reset66-v3`。
  - 關掉重開 3 次仍不是這個版本 → 先停在這裡,回報「第 4 步」。

## B. 舊資料還在嗎?(之前有真實紀錄才需要做,沒有就跳到 C 段)

- [ ] **5.** 今日頁上方的「完成日」「第 X 天」「連續」「Lv / XP」和更新前差不多(今天還沒打卡的話,數字可能少今天這一份)。
- [ ] **6.** 點今日頁日期左邊的「‹」看前幾天:之前打的勾都還在。
- [ ] **7.** 點下方的「習慣」:你的習慣都在,名稱、排程沒變。
- [ ] **8.** 點「設定」,在「備份」區塊記下「上次匯出」現在顯示什麼(第一次更新到這版應該是「尚未匯出過」):______________

## C. 匯出備份到「檔案」App

- [ ] **9.** 「設定 → 備份」點紫色的「匯出備份」。
  - 應該從下方跳出 iPhone 的**分享選單**,上面有一個 `reset66-backup-年-月-日.json` 的檔案。
- [ ] **10.** 在分享選單往下找,點「**儲存到「檔案」**」。
- [ ] **11.** 選「我的 iPhone」或「iCloud 雲碟」,選一個好找的資料夾(也可以新建一個「Reset66」資料夾),點右上角「儲存」。
- [ ] **12.** 回到 Reset66:畫面下方短暫出現「已匯出備份」,「上次匯出」變成今天的日期。
- [ ] **13.** 打開 iPhone 的「**檔案**」App,到剛剛的資料夾:看得到 `reset66-backup-….json`。長按它 →「簡介」,大小不是 0(通常是幾 KB)。

> **如果第 9–12 步有任何奇怪的地方**(分享選單沒出現、畫面變成一堆文字、app 卡住、跳出錯誤、按了沒反應……),先不要重試,做這兩件事再回報:
> - (a)到「檔案」App 找:**到底有沒有存到檔案?**
> - (b)回 Reset66「設定」看:**「上次匯出」有沒有變成今天?**
>
> 「上次匯出」變成今天,但「檔案」裡**沒有**檔案 → 這是 bug,請一定要回報(連同第 8 步記下的值)。

- [ ] **14.** 測試「取消分享」:再按一次「匯出備份」,分享選單出現後**不要選任何東西**,直接往下滑或點右上角 ✕ 關掉。
  - 應該:**不會**出現「已匯出備份」;app 正常可用。

## D. 取消匯入(什麼都不應該改變)

- [ ] **15.** 「設定 → 備份」點「匯入備份」。iPhone 會打開選檔畫面;點下方「瀏覽」,找到第 11 步存的那個 `.json` 檔,點它。
- [ ] **16.** 出現「匯入備份」視窗,內容是:匯出時間(剛剛)、起始日、習慣數、有紀錄的天數,還有一段黃色警告「匯入會覆蓋這台裝置上目前的所有資料…」。
- [ ] **17.** 點最下面的「取消」。
  - 視窗關掉,沒有出現「已匯入備份」;今日頁、「上次匯出」都和剛剛一樣。

## E. 從備份還原

- [ ] **18.** 再做一次第 15 步,選同一個檔案。
- [ ] **19.** 這次點紫色的「**覆蓋並匯入**」。
  - 出現「已匯入備份」,自動回到今日頁。
- [ ] **20.** 檢查資料完整:今日頁數字、前幾天的勾、「習慣」頁都和匯出前一樣;今日頁上方**沒有**黃色的備份提醒。

## F. 資料保護狀態

- [ ] **21.** 「設定 → 儲存空間」,「持久化儲存」顯示的是(圈一個):
  `已啟用持久化儲存` / `未啟用` / `此瀏覽器不支援` / 其他:______________
  (哪一個都不算失敗,記下來就好。)

## G. 版面(瀏海與底部橫條)

- [ ] **22.** 「設定」頁捲到最上面:「計畫」標題沒有被瀏海/動態島或時間電量列擋住。
- [ ] **23.** 「設定」頁捲到最下面:「關於」和版本號看得到,沒有被下方分頁列或螢幕最底的白色橫條擋住。
- [ ] **24.** 再打開一次「匯入備份」視窗(第 15 步),確認「覆蓋並匯入」「取消」兩個按鈕完整露出,沒有被底部橫條蓋住。看完點「**取消**」。
- [ ] **25.** 整個過程中文字沒有被切掉、沒有需要左右滑才看得到的內容。

## H. 離線

- [ ] **26.** 從右上角往下滑打開控制中心,開啟**飛航模式**。
- [ ] **27.** 把 Reset66 完全關掉(同第 3 步),再從主畫面打開:app 正常開啟,資料都在。
- [ ] **28.** 關閉飛航模式。

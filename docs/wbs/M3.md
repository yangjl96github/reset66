## 驗收標準(里程碑層級)
1. 匯出 → 清空 → 匯入後,狀態與**匯出完成後**的狀態**完全一致**(deep equal)。匯出檔內的 `meta.lastExportAt` 即為匯出當天(見下方「實作期間決策」D5)。
2. 損毀或不相符的 JSON(含匯入檔與 `localStorage` 內資料)**不會讓 app 崩潰**,且不會覆蓋現有資料。
3. M2 產生的 v1 資料在升級後**自動遷移**到 v2,不遺失任何紀錄。
4. iPhone:可透過分享選單把備份存到「檔案」App,並能從「檔案」匯入。
5. 已向瀏覽器請求持久化儲存,設定頁顯示結果。

## 資料結構變更:schemaVersion 1 → 2
新增 `meta`(非衍生資料,需存檔):
```jsonc
"meta": {
  "lastExportAt": null   // 最近一次成功匯出的邏輯日期 YYYY-MM-DD;null = 從未匯出
}
```
遷移 v1 → v2:補上 `meta: { lastExportAt: null }`;habit 缺 `archivedAt` 時補 `null`。

### M3-1 Schema validation and migration framework
- 新增純函式模組 `src/logic/schema.js`:
  - `CURRENT_SCHEMA_VERSION = 2`
  - `migrate(raw)`:依版本逐步遷移(v1→v2…),回傳新物件,不修改輸入。
  - `validateState(obj)` → `{ ok: true, state } | { ok: false, errors: string[] }`:檢查 program(日期、數值範圍)、habits(id 唯一、欄位型別、days 範圍)、logs(日期鍵合法、狀態只能 done/skipped)、meta。
  - 版本號大於目前版本 → 拒絕(提示「請先更新 app」)。
- `store.js` 載入時:parse → migrate → validate;遷移後立即寫回。驗證失敗沿用現有「另存損毀副本」機制。
- `state.js` 的 `createInitialState` 產生 v2 結構。
- **UT**:v1→v2、遷移不改輸入、已是 v2 不變、各種不合法結構、未來版本被拒。
- **驗收**:`npm test` 全綠;用 M2 的 v1 資料載入後內容不變且多了 `meta`。

### M3-2 JSON export
- 匯出檔格式(信封):
  ```jsonc
  { "app": "reset66", "format": 1, "appVersion": "0.3.0", "exportedAt": "2026-11-20T21:05:00+08:00", "data": { /* 完整 state */ } }
  ```
- 檔名:`reset66-backup-YYYY-MM-DD.json`。
- 支援 `navigator.canShare({ files })` 時用分享選單(iPhone 可存到「檔案」),否則用下載連結。
- 成功後把 `meta.lastExportAt` 設為今天(使用者取消分享則不更新)。
- 信封的組裝與解析放在純函式(例如 `src/logic/backup.js`),UT 覆蓋。
- **驗收**:PC 下載得到合法 JSON;iPhone 出現分享選單。

### M3-3 JSON import
- 設定頁「匯入備份」→ 選檔(`accept=".json,application/json"`,上限 5 MB)。
- 接受信封格式,也接受直接是 state 的舊檔;之後 migrate → validate。
- 匯入前顯示預覽:匯出時間、起始日、習慣數、有紀錄的天數,並明確提示「會覆蓋目前資料」,需使用者確認。
- 覆蓋前把目前資料另存到 `reset66.v1.backup.<ISO 時間>`,最多保留 3 份。
- 任何錯誤(非 JSON、不是 Reset66 檔、版本過新、結構不合法)→ 顯示中文錯誤訊息,資料不變。
- **驗收**:匯出 → 清空 → 匯入後 deep equal;損毀檔不崩潰、不改資料;取消確認不改資料。

### M3-4 Request persistent storage
- 在完成引導、或 app 啟動且已有資料時呼叫 `navigator.storage.persist()`(若 `persisted()` 已為 true 則略過)。
- 設定頁顯示「已啟用持久化儲存」或「未啟用」與說明(iPhone 請加入主畫面並定期匯出)。
- 不支援的瀏覽器顯示「此瀏覽器不支援」,不報錯。

### M3-5 14-day export reminder
- 純函式 `shouldRemindExport(state, today)`:計畫已開始,且距 `meta.lastExportAt`(從未匯出則以 `program.startDate` 起算)≥ 14 天 → true。UT 覆蓋邊界(13/14 天、未開始、從未匯出)。
- 今日頁顯示一則溫和提醒,點擊前往設定頁的匯出;匯出成功後自動消失。

## 實作期間決策(PM 核准,2026-11-15)
| ID | 決策 | 理由 |
|---|---|---|
| D1 | 引導頁加「從備份還原」按鈕 | 設定頁要有資料才進得去;清空資料或換手機時必須能從引導頁還原 |

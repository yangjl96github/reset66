### M4-1 Stats logic(純函式 + UT,先做)
新增 `src/logic/stats.js`,只依賴 `progress.js` / `dates.js`,不碰 DOM、不呼叫 `Date.now()`。
- `heatmapCells(state, today, { weeks = 12 } = {})`:
  - 回傳以「週」為欄、週日開頭的格子陣列;最後一欄是 `today` 所在的那一週。若計畫天數超過 `weeks` 週,只取最近的。
  - 每格:`{ date, inProgram, isFuture, status, done, counted, level }`。
    - `inProgram = startDate <= date <= today`;計畫外或未來的格子 `status = null`、`level = 0`。
    - `status` 沿用 `DayStatus`(`complete` / `incomplete` / `pending` / `rest`),今天未達標為 `pending`。
    - `level`(色階 0–4):`rest`/計畫外 = 0;`counted > 0` 時依 `done / counted`:0 → 1、(0, 0.5) → 2、[0.5, 1) → 3、1 → 4。
- `habitCompletionRates(state, today)`:每個習慣(含已封存,標記 `archived`)回傳 `{ id, title, archived, done, counted, rate }`。
  - 分母 `counted`:計畫開始到**昨天**為止,該習慣「應做且未略過」的天數;**今天只有已完成時才算進分母與分子**(今天還沒做不拉低完成率)。
  - `rate = counted > 0 ? done / counted : null`(UI 顯示「—」)。
  - 排序:未封存在前,依 `state.habits` 原順序。
- `summaryStats(state, today)`:完成日數、最長 streak、目前 streak、總 XP、等級(重用既有函式,不重算規則)。
- **UT**:計畫未開始、跨月 / 閏年週對齊、超過 12 週只取最近、休息日色階、今天 pending、略過不計分母、今天未做不影響完成率、封存日之後不計、`createdAt` 之前不計。

- 不提供刪除這些 key 的功能(避免誤刪;M4 範圍外)。
